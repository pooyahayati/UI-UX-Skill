# Release 3.6.0

## Authority

On 2026-11-01 the owner explicitly requested committing, pushing and merging R12,
publishing a new release, then updating the local Skill. This supersedes the
implementation-only delivery restriction in [R12](../R12_EXECUTION.md#authority).
It includes release metadata, required verification, PR/merge, the existing sole
GitHub publisher, actual downloaded-artifact verification, a backed-up managed
update of `ui-ux-skill` and delivery closeout. It does not authorize unrelated
Skill updates, new product dependencies or production WordPress changes.

Version 3.6.0 is the additive WordPress settings-findability/internal-page release
after 3.5.1. All six [R12 packages](../../ROADMAP.md#r12-wordpress-admin-design-and-settings-findability)
were accepted before this delivery instruction. Existing real-admin/model
evidence remains valid within its exact source scope; release-version metadata
compatibility is recorded separately and never called a fresh evaluation.

## Delivery gates

The roadmap owns live status. Before integration, validate release metadata and
the explicit version-only evidence bridge, retained regressions, source/resource
routes, both candidate packages and the native Trivy source/extracted-artifact
scan. Exact-head PR CI must pass before merge, including applicable Linux symlink
checks previously skipped on Windows.

The existing main-branch release workflow is the sole publisher. Verify its
merge/tag binding and independently download all three published assets; check
their checksums, versions, canonical source/license identity and extracted routes.
Only then stage the exact release with the official installer and update the
managed local installation, preserving Head integration and a recoverable backup.
Observed candidate, integration, published-download and installation evidence
will be recorded below as each boundary completes.
