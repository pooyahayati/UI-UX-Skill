# Release 3.5.0

Authority and live delivery status: [Roadmap](../../ROADMAP.md#release-350).

## Scope

The dashboard shadcn/ui default and optional product-driven interactive motion
guidance are the only new capabilities. Existing stack/native-host constraints,
accessibility floors and owner-control boundaries remain intact. No application
library is bundled or installed into a product by this release.

Source acceptance: [shadcn review](../../evals/shadcn/REVIEW.md) and
[motion review](../../evals/motion/REVIEW.md). Their local 3.4.0-named test packages
and original source-only authorization are historical checkpoints, not 3.5.0
published artifacts or limits on the owner's later delivery instruction.
