# Owner request — service web application

Our English service application already has an owner-only Appearance page. It
lets me preview and publish fonts, colors and spacing, and restore an earlier
version. There are saved configurations in use, including some from before we
had any icon settings. There is also a public product reader and a request dialog.

I want to change the icons from that page too. I should be able to see the choices,
switch between an outline and a solid family, and pick another search icon without
asking a programmer to edit each page. Search, add, edit, delete and settings are
the common uses. The app also has back navigation and expandable request guidance.
I may use a family that doesn't include every icon. Could I simply paste a custom
SVG into the settings when one is missing? I don't want to lose our existing color
and font settings or old versions when this is added.

Please recommend a practical implementation and acceptance plan for the existing
app. Keep it English and LTR; don't build a new product or change the framework.
Work with the existing appearance lifecycle. This request is for a plan, not
permission to install a package, publish to production or modify our application.
