# Product request

We are planning an English-only maintenance work-order web application. Managers assign jobs; technicians update assigned jobs. Each customer organization already has an owner administration area and its own data. We have approved a restrained blue palette, system sans typography, balanced spacing and an accessible responsive layout. Authentication and organization membership already exist and are outside this design assignment.

Owners should be able to adjust supported presentation choices after delivery, without asking a developer to edit every screen. Please use the supplied UI/UX skill to prepare the next implementation plan and an initial product design handbook for this request. Explain which decisions you recommend and what must be checked before delivery. No product implementation, installation, publication or production access is authorized in this planning exercise.
