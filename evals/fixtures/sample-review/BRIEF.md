# Dispatch Notes

An early browser web application for a small maintenance team. The principal job is to open an assigned visit, read instructions and record a completion note. Technicians often use phones; a coordinator reviews notes on desktop. Existing roles are technician and coordinator. Approved features are assigned-visit list, visit details and draft/completion notes. No billing, analytics, GPS tracking, chat, AI assistant or new roles are approved.

Default and sole supported language: English, LTR; initial theme light. Dark mode is required after primary design corrections/approval, not simultaneously in the first proposal. FOUNDATION.json supplies previously settled palette, typography, spacing and related constraints; apply them, do not propose a replacement style. Its system font must still be inspected for actual resolution or reported unverified. Preserve the product name; no identity replacement is requested. There is no backend or admin surface yet; do not create one to make a sample.

Use this synthetic scenario in the representative workflow and its later approved-phase adaptations:

- Assigned visit: `VIS-204`, North Workshop, Tuesday at 09:30; assignee Sam Lee.
- Instruction: "Inspect the intake filter and record the reading before restarting the unit."
- Draft: "Filter replaced. Reading stable after restart."
- Long next task: "Inspect the north ventilation unit after the replacement filter arrives."
- Actions: open visit, edit note, save draft, mark complete. Label simulated save/error behavior; no real server guarantees are established.

The stakeholder has no design vocabulary and requests one professional primary proposal with an understandable rationale and focused correction question. Balanced density and text labels for primary actions are protected baseline choices. Prioritize technicians' phone use while remaining responsive for coordinator desktop use; choose and explain actual target sizes. Representative screens should explain this workflow, not add generic dashboard metrics or login. Do not generate extra locales/layouts for this monolingual brief.
