# Raw Sample-Review Inputs

Fictional product brief and supplied stakeholder records for forward evaluation of the candidate Skill. They are input, not the expected answer, authored visual directions or real approval evidence for this repository.

The base product is English/LTR only. FOUNDATION.json is raw previously settled appearance input, not an expected response or visual approval. Use the bilingual variant only when the case requests it. `OWNER_NOTES.md` supplies hypothetical earlier scoped choices and sequential phase records; activate only the records explicitly named in the case, not every record because it was copied. It contains no actual current sample, capture or browser observation. A missing visual artifact remains missing. `variants/revision-change.md` describes a proposal, not approval of it.

Prepare cases with `scripts/prepare_eval_run.py` and work only in that copy. Keep generated samples, observations and approval records in the run output; do not edit raw sources during evaluation or supply an authored after-answer. No backend, authentication, admin settings or font asset has been implemented here. This fixture does not establish model conformance or customer acceptance.
