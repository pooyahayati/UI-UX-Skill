# Bounded icon-state specimen

This synthetic English mobile disclosure verifies one optional morphicons 2.0.2
DOM adapter. It uses the existing `runtime_appearance.py` HTTP/session/CSRF/store
and `runtime_icons.py` prepared artwork. It adds no settings engine or WordPress
component and is excluded from the portable Skill. There is no live catalog call,
Aria asset import, font upload, production integration or real visit mutation.

The selected original outline/plain closed/open pair morphs. Solid/badge choices
remain the owner's chosen artwork and render statically; this is the specimen's
bounded support, not a claim that engine 2.x cannot morph fills. The library's MIT
notice and all package bytes are pinned in `provider.json`; artwork is original
repository MIT content, with its source identity in the runtime report. Aria's
exporter was inspected separately, not executed or assumed equivalent to 2.x.

The existing persisted `reduced` preset resolves to zero duration and is retained
as the fixture's owner-off equivalent. No schema rename or migration is introduced.
Personal off and OS reduction lower the effective policy. A preference change
destroys/settles the active driver; it does not rely on its next morph call.
Only the disclosure family, variant and motion consumer are claimed here.

## Reproduction

Use an isolated directory outside repository source. Obtain the exact npm tarball
in `provider.json`, verify its SHA-512 integrity, extract safely and retain LICENSE.
Use esbuild 0.28.2 with the recorded command to prepare the local split/minified
bundle. The runner verifies every source-package and built-module SHA-256 before
executing. Do not commit node_modules, provider bundles or temporary databases.

Run `node scripts/test_icon_morph_browser.mjs` with these existing-tool paths:

- `PYTHON`: Python executable.
- `PLAYWRIGHT_MODULE`: installed Playwright module.
- `BROWSER_EXECUTABLE`: installed compatible Chromium-family browser.
- `MORPHICONS_PACKAGE`: extracted npm `package` directory.
- `MORPHICONS_BUNDLE`: recorded build output directory.
- `ICON_ARTIFACT_DIR`: dedicated output directory outside the repository.

No tool download is performed by the runner. It starts/stops its own loopback
server and browser; synthetic SQLite remains in its unique host temp directory.
Playwright routes only static specimen/vendor files. All appearance operations
use the real existing authenticated API. Private preview is explicitly applied to
the specimen view; publication reaches it on reload, not a claimed push subscription.

## Recorded acceptance

[Runtime report](../../r14/evidence/icon-runtime.json) and
[mobile capture](../../r14/evidence/mobile.png): 15 assertions/observation groups,
Edge 156.0.4314.58 at 390×844. Includes normal/keyboard, rapid interruption, live OS
reduction, personal/owner off, unsupported-pair static fallback, private preview,
save/reopen/publish, invalid/denied writes, reset/rollback/history, configuration
failure, provider failure and cleanup. No clipping was observed in the capture.

The first unminified module route exceeded the preselected 16,000-byte gzip ceiling
(17,671 bytes); bundling/minification reduced actual requested provider modules to
9,611 gzip bytes, with a zero-provider static baseline. The budget was not raised.
Recorded synchronous click-handler samples were 0–0.2 ms static and about 0.1–0.7 ms
with morphing. These are local emulation observations, not FPS, INP, physical-device
performance, assistive-technology certification or measured user speed.

During debugging, the installed Chrome emulation changed `matchMedia().matches`
without delivering a change event in a minimal probe. Edge delivered that event.
The final runner uses timer polling for the live-event check and verifies an active
morph before switching preference, then final actual geometry. A progress value of
1 before a driver's first frame is not sufficient evidence of settled geometry.
