# Continuing Dispatch Notes

Browser web application for maintenance technicians and coordinators. Technicians open assigned visits and write draft/completion notes, mainly on phones; coordinators review on desktop. Approved existing note limit is 240 characters; validation, draft-save recovery and visible text action labels are part of scope. Existing roles/permissions and that limit must not change.

English is default and sole supported language, LTR. Light and derived dark were hypothetically reviewed in the supplied baseline; no second locale is requested. Reuse balanced density, palette, typography, spacing, low motion and the current browser stack. No billing, GPS tracking, analytics, admin backend, new role, framework migration or new dependency is approved. DESIGN.md describes intent/authority; ui-tokens.json owns supplied values. A new UI need does not automatically reopen every foundation choice.
