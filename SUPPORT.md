# Support

For questions, bug reports, and feature requests related to **UI/UX Skill**, use the GitHub issue tracker:

https://github.com/pooyahayati/UI-UX-Skill/issues

Before opening an issue:

1. Check the README and current release notes.
2. Confirm the issue occurs with the current version.
3. Remove API keys, passwords, tokens, private repository content, customer data, and other sensitive information.
4. Use the provided Bug Report or Feature Request template when appropriate.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md).
