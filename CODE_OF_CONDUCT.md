# Code of Conduct

UI/UX Skill is intended to be a practical, professional open-source project.

Contributors and participants are expected to:

- discuss ideas and implementation choices respectfully
- critique work, not people
- provide reproducible examples when reporting problems
- avoid harassment, discrimination, threats, or personal attacks
- respect privacy and do not publish credentials, private data, or sensitive project information
- keep discussions relevant to the project

Maintainers may edit, hide, lock, or remove contributions or discussions that violate these expectations.

Good-faith disagreement about design, UX, accessibility, RTL/LTR behavior, implementation strategy, or project scope is welcome when it remains technical and constructive.
