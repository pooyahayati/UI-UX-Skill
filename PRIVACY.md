# Privacy Policy

**UI/UX Skill** is an instruction-only Skill and skills-only Plugin package maintained by Pooya Hayati.

Last updated: 2026-09-20

## Data collection

The package itself does not operate a remote server, create user accounts, collect analytics, store conversations, or transmit user data to the maintainer.

The Skill provides instructions that a compatible host can apply inside the user's current environment. Files, repositories, connected tools, and project data accessed during execution remain governed by the user's host environment, enabled tools, permissions, and the policies of those services.

## External services

The core package does not require an external MCP server or a third-party account.

If a user independently enables tools, MCP servers, repositories, or services while using the Skill, those services have their own privacy practices and terms.

## Local project files and configuration

The Skill may instruct the agent to inspect or modify frontend project files when the user requests implementation work.

It may create or update a local `design-profile.md` to preserve approved or delegated design decisions and their provenance.

If a product implements runtime UI governance, owner design configuration, user preferences, saved views, audit history, or version history, that data is stored and governed by the user's own application architecture. The maintainer does not receive those records through this package.

## Sensitive information

The Skill instructs agents to avoid unnecessarily copying secrets, credentials, customer data, PII, private saved views, private audit records, or private repository content into screenshots, reports, issues, examples, or generated artifacts.

Users should not include credentials, API keys, passwords, private tokens, or unnecessary personal data in public bug reports or contribution examples.

## Changes

Material changes to this policy are documented in repository history and release notes.

## Contact

For privacy questions, open a minimal GitHub issue without sensitive information:
